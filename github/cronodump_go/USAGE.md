# Руководство по использованию Cronodump Go

## Быстрый старт

1. **Сборка проекта:**
```bash
go build -o cronodump_go .
```

2. **Базовое использование (все базы в папке и подпапках):**
```bash
./cronodump_go -input /home/bd_cronos -verbose
```

3. **С импортом в ClickHouse (каждая база обрабатывается полностью):**
```bash
./cronodump_go -input /home/bd_cronos -clickhouse "tcp://localhost:9000" -verbose
```

## Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `-input` | Путь к папке с базой данных Cronos (обязательный) | - |
| `-output` | Папка для сохранения SQL файлов | `./output` |
| `-clickhouse` | URL подключения к ClickHouse | - |
| `-verbose` | Подробный вывод процесса | `false` |
| `-cleanup` | Удалить временные файлы после импорта | `true` |
| `-batch` | Размер батча для вставки данных | `1000` |

## Примеры использования

### 1. Конвертация без импорта в ClickHouse
```bash
./cronodump_go -input /data/cronos_db -output ./sql_files -verbose
```

### 2. Конвертация с импортом в ClickHouse
```bash
./cronodump_go \
  -input /data/cronos_db \
  -clickhouse "tcp://localhost:9000" \
  -verbose
```

### 3. Только экспорт SQL файлов
```bash
./cronodump_go -input /data/cronos_db -output ./export -cleanup=false
```

### 4. С настройкой размера батча
```bash
./cronodump_go -input /data/cronos_db -batch 5000 -verbose
```

## Структура базы данных Cronos

Программа автоматически находит все базы данных Cronos в указанной папке и подпапках. Каждая база данных должна содержать:
- `CroStru.dat` - структура базы данных
- `CroStru.tad` - индекс структуры
- `CroBank.dat` - данные базы данных
- `CroBank.tad` - индекс данных

**Поиск в подпапках:** Программа рекурсивно ищет все папки, содержащие файлы `CroStru.dat` и `CroBank.dat`.

## Логика обработки

Программа обрабатывает каждую найденную базу данных **последовательно**:

1. **Конвертация** - парсинг структуры и данных базы
2. **Объединение** - создание одного файла по зависимостям между таблицами
3. **Импорт** - загрузка данных в ClickHouse (если указан URL)
4. **Очистка** - удаление временных SQL файлов
5. **Следующая база** - переход к следующей найденной базе

Это обеспечивает экономию места на диске и позволяет обрабатывать большие объемы данных.

## Выходные файлы

После успешной конвертации в папке `output` будут созданы:
- `{table_name}.sql` - SQL файлы для каждой таблицы
- Каждый файл содержит CREATE TABLE и INSERT statements для ClickHouse

## Транслитерация

Все русские имена автоматически транслитерируются:
- `Пользователи` → `polzovateli`
- `Дата создания` → `data_sozdaniya`
- `Системный номер` → `sistemnyi_nomer`

## Связи между таблицами

Программа автоматически:
1. Анализирует связи между таблицами по типам полей (7, 8, 9, 17)
2. Объединяет связанные таблицы в одну
3. Добавляет поля из связанных таблиц с префиксом имени таблицы

## Требования

- ClickHouse (опционально, для прямого импорта)

## Устранение неполадок

### Ошибка "файл CroStru.dat не найден"
Убедитесь, что указанная папка содержит файлы базы данных Cronos.

### Ошибка подключения к ClickHouse
Проверьте, что ClickHouse запущен и доступен по указанному адресу.

### Ошибки транслитерации
Проверьте, что в именах таблиц и полей используются только кириллические и латинские символы.
