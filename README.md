# Конвертер Cronos → ClickHouse

Программа для конвертации баз данных Cronos в ClickHouse, написанная на Go. Это переписанная версия библиотеки [cronodump](https://github.com/alephdata/cronodump) с улучшениями и оптимизациями.

## Возможности

- 🔄 Автоматическое обнаружение и парсинг баз данных Cronos
- 🌐 Транслитерация русских имен таблиц и колонок в латиницу
- 📊 Все данные сохраняются как строки для максимальной совместимости
- ⚡ Батчевая обработка для высокой производительности
- 🔧 Гибкая конфигурация через переменные окружения
- 📈 Подробное логирование процесса конвертации
- 🏗️ Автоматическое создание таблиц в ClickHouse

## Установка

1. Убедитесь, что у вас установлен Go 1.21 или выше
2. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd cronos-converter
```

3. Установите зависимости:
```bash
go mod download
```

4. Соберите программу:
```bash
go build -o cronos-converter
```

## Конфигурация

Программа настраивается через переменные окружения:

### Обязательные переменные

- `CRONOS_DB_PATH` (или `pach_to_db`) - путь к папке с базами данных Cronos
- `CLICKHOUSE_DSN` (или `clichause_dsn`) - адрес ClickHouse сервера

### Дополнительные переменные

- `CLICKHOUSE_DATABASE` - имя базы данных ClickHouse (по умолчанию: `cronos_data`)
- `CLICKHOUSE_USER` - пользователь ClickHouse (по умолчанию: `default`)
- `CLICKHOUSE_PASSWORD` - пароль ClickHouse (по умолчанию: `default`)
- `BATCH_SIZE` - размер батча для вставки (по умолчанию: `1000`)
- `VERBOSE` - детальное логирование (`true`/`false`)

### Пример конфигурации

```bash
export CRONOS_DB_PATH="/home/usersamba/smb/"
export CLICKHOUSE_DSN="localhost:9000"
export CLICKHOUSE_DATABASE="cronos_data"
export CLICKHOUSE_USER="default"
export CLICKHOUSE_PASSWORD=""
export VERBOSE="true"
```

**Примечание:** Программа подключается к базе данных `default` в ClickHouse, но создает и использует рабочую базу данных, указанную в `CLICKHOUSE_DATABASE`.

## Использование

1. Установите переменные окружения
2. Запустите программу:

```bash
./cronos-converter
```

Или напрямую через Go:

```bash
go run .
```

Для удобства также можно использовать готовый скрипт:

```bash
./example.sh
```

## Структура данных

Программа создает таблицы в ClickHouse со следующей структурой:

- Все поля из исходной таблицы Cronos (как `String`)
- `cronos_import_timestamp` - время импорта
- `cronos_source_folder` - имя исходной папки
- `cronos_source_table` - имя исходной таблицы
- `cronos_record_count` - общее количество записей в таблице

### Именование таблиц

Имена таблиц формируются как: `{folder_name}_{table_name}` с транслитерацией:

- Русские символы конвертируются в латиницу
- Специальные символы заменяются на подчеркивания
- Соблюдаются правила именования ClickHouse
- Избегаются зарезервированные слова

## Архитектура

Программа состоит из следующих компонентов:

- **Config** - управление конфигурацией
- **CronosParser** - парсинг баз данных Cronos
- **Transliteration** - транслитерация имен
- **ClickHouseClient** - работа с ClickHouse
- **CronosConverter** - основная логика конвертации

## Особенности

- Все данные из Cronos сохраняются как строки (`String` тип в ClickHouse)
- Поддержка множественных форматов файлов Cronos
- Устойчивость к ошибкам - программа продолжает работу при ошибках отдельных таблиц
- Автоматическое создание партиций по месяцам
- Оптимизированные настройки ClickHouse для лучшей производительности

## Логирование

Программа выводит подробную информацию о процессе:

- Обнаруженные базы данных и таблицы
- Процесс создания таблиц
- Прогресс вставки данных
- Ошибки и предупреждения

## Troubleshooting

### Ошибка подключения к ClickHouse

Убедитесь, что:
- ClickHouse запущен и доступен по указанному адресу
- Указаны правильные учетные данные
- Нет проблем с сетевым подключением

### Ошибка чтения файлов Cronos

Проверьте:
- Путь к базам данных указан корректно
- У программы есть права на чтение файлов
- Файлы не повреждены

### Проблемы с транслитерацией

Программа автоматически обрабатывает:
- Русские, украинские и белорусские символы
- Специальные символы и пунктуацию
- Зарезервированные слова ClickHouse

## Производительность

Для оптимальной производительности:

- Используйте SSD диски для ClickHouse
- Настройте размер батча в зависимости от объема данных
- Убедитесь в достаточном количестве RAM
- Рассмотрите использование отдельного диска для логов ClickHouse
