# Cronos to ClickHouse Converter

Конвертер баз данных Cronos в ClickHouse, написанный на Go.

## Описание

Этот проект представляет собой переписанную на Go версию [cronodump](https://github.com/metall13/cronodump) с дополнительной функциональностью экспорта в ClickHouse.

### Основные возможности

- Парсинг баз данных CronosPro
- Транслитерация русских названий таблиц в латиницу
- Приведение названий к стандартам ClickHouse
- Экспорт данных в ClickHouse батчами по 200 записей
- Создание SQL файлов при недоступности ClickHouse
- Поддержка различных версий формата Cronos (v3, v4)
- Декодирование KOD защищенных баз данных

### Принцип именования таблиц

Имя таблицы формируется как: `{имя_папки_базы}_{имя_таблицы}`
- Русские символы транслитерируются в латиницу
- Недопустимые символы заменяются на подчеркивания
- Имена приводятся к стандартам ClickHouse

## Установка

```bash
go mod tidy
go build -o cronos-converter
```

## Использование

### Базовое использование

```bash
./cronos-converter -db /path/to/cronos/databases -v
```

### Параметры

- `-db` - путь к директории с базами Cronos (по умолчанию: `/home/bd_cronos`)
- `-config` - путь к файлу конфигурации (по умолчанию: `config.json`)
- `-v` - подробный вывод

### Конфигурация

Создайте файл `config.json`:

```json
{
  "database_path": "/home/bd_cronos",
  "output_path": "cronos-export",
  "clickhouse": {
    "host": "localhost",
    "port": 9000,
    "database": "default",
    "username": "default",
    "password": "",
    "connection_string": ""
  }
}
```

## Структура проекта

- `main.go` - основной файл приложения
- `config.go` - работа с конфигурацией
- `converter.go` - основная логика конвертации
- `cronos_parser.go` - парсер баз данных Cronos
- `parser_methods.go` - дополнительные методы парсера
- `byte_reader.go` - утилиты для чтения бинарных данных
- `kod_decoder.go` - декодер KOD кодирования
- `clickhouse_exporter.go` - экспорт в ClickHouse

## Поддерживаемые типы данных Cronos

| Тип Cronos | Тип ClickHouse | Описание |
|------------|----------------|----------|
| 0 | UInt32 | Системный номер (PRIMARY KEY) |
| 1 | Int32 | Целое число |
| 2 | String | Строка (VARCHAR) |
| 3 | String | Текст (словарь) |
| 4 | Date | Дата |
| 5 | DateTime | Время |
| 6 | String | Ссылка на файл |

## Особенности

- Автоматическое обнаружение баз данных в директории
- Поддержка регистронезависимого поиска файлов
- Обработка расширенных записей
- Декодирование KOD защищенных данных
- Fallback на SQL файлы при недоступности ClickHouse
- Батчевая обработка данных для оптимальной производительности
