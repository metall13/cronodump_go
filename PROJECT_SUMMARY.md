# Cronodamp - Проект завершен

## Описание

Библиотека **cronodamp** успешно переписана на Golang для экспорта данных из баз Kronos в ClickHouse.

## Ключевые возможности

✅ **Автоматическое обнаружение таблиц** - рекурсивный поиск всех файлов (.txt, .csv, .dat) в папках
✅ **Транслитерация названий** - корректное преобразование русских названий в латиницу по правилам ClickHouse  
✅ **Именование таблиц** - формат `папка_таблица` с транслитерацией
✅ **Строковые данные** - все данные экспортируются как String в ClickHouse
✅ **Различные разделители** - поддержка табуляции, точки с запятой, запятой
✅ **Батчевая загрузка** - эффективная вставка данных большими порциями
✅ **Статистика и логирование** - детальная информация о процессе экспорта
✅ **CLI интерфейс** - удобная командная строка
✅ **Обработка ошибок** - устойчивость к ошибкам в отдельных файлах

## Использование

### Переменные окружения (как в требованиях)
```bash
export KRONOS_DB_PATH="/home/usersamba/smb/"    # Путь к базам
export CLICKHOUSE_DSN="localhost:9000"          # Строка подключения
```

### CLI команды
```bash
# Показать все таблицы
./build/cronodamp --list

# Проверить подключение к ClickHouse
./build/cronodamp --validate

# Экспортировать все таблицы
./build/cronodamp

# Экспортировать конкретный файл
./build/cronodamp --file "/path/to/file.txt"

# Экспортировать папку
./build/cronodamp --folder "folder_name"

# Режим отладки
./build/cronodamp --debug
```

### Программное использование
```go
import "cronodamp"

config := cronodamp.NewConfigFromEnv()
exporter, err := cronodamp.NewExporter(config)
if err != nil {
    log.Fatal(err)
}
defer exporter.Close()

// Экспорт всех таблиц
err = exporter.ExportAll()
```

## Логика именования таблиц

Согласно требованиям - **берем имя папки и имя таблицы**:

- `Отчеты/Продажи.txt` → таблица `otchety_prodazhi`
- `База данных/Клиенты.csv` → таблица `baza_dannyh_klienty`
- `Reports/Sales_2024.dat` → таблица `reports_sales_2024`

## Структура таблиц в ClickHouse

Каждая таблица содержит:
- **Все колонки из файла** (как String)
- `import_timestamp` - время импорта
- `source_table` - имя исходной таблицы  
- `source_folder` - имя папки
- `source_file_path` - полный путь к файлу
