# Changelog - Конвертер Cronos → ClickHouse

## Версия 1.0 - 2025-08-10

### ✅ Основные возможности

- Полная переписка библиотеки cronodump с Python на Go
- Автоматическое обнаружение и парсинг баз данных Cronos
- Транслитерация русских имен таблиц и колонок в латиницу
- Сохранение всех данных как строки для максимальной совместимости
- Батчевая обработка для высокой производительности
- Подробное логирование процесса конвертации

### 🔧 Конфигурация ClickHouse

- Подключение к базе данных `default` по умолчанию
- Использование стандартных учетных данных:
  - Username: `default`
  - Password: `` (пустой)
  - Database: `default` (для подключения)
- Адрес подключения: `Addr: []string{config.ClickHouseAddr}`
- Автоматическое создание рабочей базы данных

### 📊 Структура данных

- Все поля из Cronos сохраняются как `String` тип
- Добавляются служебные поля:
  - `cronos_import_timestamp` - время импорта
  - `cronos_source_folder` - имя исходной папки
  - `cronos_source_table` - имя исходной таблицы
  - `cronos_record_count` - общее количество записей

### 🌐 Транслитерация

- Поддержка русских, украинских и белорусских символов
- Автоматическая замена специальных символов на подчеркивания
- Избегание зарезервированных слов ClickHouse
- Формат имен таблиц: `{folder_name}_{table_name}`
