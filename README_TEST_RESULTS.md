## Функциональные возможности

### Поддерживаемые форматы экспорта
- CSV файлы с корректным экранированием специальных символов
- ClickHouse с батчевой загрузкой данных

### Особенности работы с русским языком
- Автоматическая транслитерация названий таблиц и колонок
- Поддержка кириллических символов в данных
- Нормализация текстовых значений

### Настройки
- Гибкая конфигурация через JSON файл
- Параметры командной строки для быстрого запуска
- Поддержка фильтрации таблиц

## Пример использования

```bash
# Экспорт всех таблиц в CSV
./cronodump -db "/path/to/kronos.fdb" -output "./export"

# Экспорт конкретной таблицы
./cronodump -db "/path/to/kronos.fdb" -table "USERS" -output "./export"

# Экспорт в ClickHouse
./cronodump -db "/path/to/kronos.fdb" -clickhouse -v

# Использование конфигурационного файла
./cronodump -config "my_config.json"
```

## Зависимости

- `github.com/ClickHouse/clickhouse-go/v2` - клиент ClickHouse
- `github.com/nakagami/firebirdsql` - драйвер Firebird
- `github.com/lib/pq` - PostgreSQL драйвер (для совместимости)

## Рекомендации для полного тестирования

1. **Установить Firebird**
   ```bash
   sudo apt-get install firebird3.0-server firebird3.0-client
   ```

2. **Настроить доступ к базам Kronos**
   - Убедиться в доступности файлов `.fdb`
   - Проверить права доступа к файлам
   - Настроить Firebird сервер

3. **Настроить ClickHouse (опционально)**
   ```bash
   docker run -d --name clickhouse -p 9000:9000 clickhouse/clickhouse-server
   ```
